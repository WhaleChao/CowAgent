## 🌐 访客页面

可将 Agent 分享为独立的对话页面，或以对话窗口的形式嵌入网站，访客打开链接即可对话，无需登录，适用于产品咨询、知识库问答、在线客服等场景：

- **独立页面**：每个页面生成独立链接，访客保留历史会话，支持自定义名称、图标、主题色、欢迎语与引导问题。

<Frame>
  <img src="https://cdn.link-ai.tech/doc/guest-share-page-zh.png" alt="访客页面" width="800" />
</Frame>

- **窗口嵌入**：复制一段代码即可嵌入网站，页面右下角显示对话入口，可限制允许嵌入的网站，配置时可直接预览嵌入效果。在线体验：[CowAgent 官网](https://cowagent.ai/zh/?chat=open)。

<Frame>
  <img src="https://cdn.link-ai.tech/doc/guest-share-embed-zh.png" alt="嵌入网页" width="800" />
</Frame>

- **数据隔离**：访客使用的 Agent 只能调用为该页面开放的工具、技能和参考资料，无法访问你的记忆、对话和工作空间，不提供命令执行，联网请求仅限公网地址；新建页面默认不开启文件写入、文件发送与联网搜索。
- **参考资料**：可直接选择知识库或其中的某个分类作为只读资料，并为每项附上用途说明。
- **访问控制**：支持访问密码、每人每日提问次数与有效期；可按访客查看对话记录，随时重置链接、停用或删除页面。

## 🎨 自定义主题

Web 控制台与桌面客户端支持主题切换，两端共用同一主题目录：

- **导入主题**：将主题 zip 包或文件夹拖入即可导入，支持自定义配色、背景壁纸与新对话页图标，主题保存在 `~/cow/system/themes/`。
- **Agent 生成主题**：描述想要的风格或附上参考图，Agent 即可生成配色、壁纸与图标，生成后可直接切换使用。
- **内置主题**：提供 Meadow、Ocean、Clay、Sakura、Lavender 五套配色，均适配浅色与深色模式。

## 🖼 主模型图像理解优化

主模型具备视觉能力时，图片作为多模态输入直接参与推理，单次调用完成理解与回答，避免经图像理解工具转述造成的细节损失，界面还原、图表分析等任务效果显著提升（Thanks @592774447 #3608）。

- **启用条件**：图像理解模型设为「自动」或与主模型一致时生效，无需额外配置。
- **上下文开销**：仅当前轮次携带图片，历史轮次保留图片引用，不重复计入 Token；请求因图片被拒绝时自动降级为纯文本重试。
- **厂商适配**：Claude、Gemini、通义千问按各自原生格式传图。
- **识别精度**：图片压缩上限提升至 3MB / 3072px，保留更多文字与细节。

## 🔗 集成配置与访问地址

「配置」页新增「集成配置」，Web 控制台与桌面客户端均已支持，集中管理访客页面、对话 API 与访问地址：

- **访问地址**：可在线修改监听 IP 与端口，保存后直接切换到新地址，无需重启，新地址不可用时恢复原地址；显示本机局域网地址，并可设置对外展示地址，用于分享链接与嵌入代码。
- **HTTPS 与域名**：支持控制台直接启用 HTTPS，并补充 nginx 反向代理部署说明（Thanks @anshlakhera048 #3774、@592774447 #3768）。
- **登录保护**：同一来源连续输错密码将被临时锁定；本机访问单独计数，外部猜测密码不会导致本机无法登录。
- **对话 API**：同一会话的并发请求按顺序处理（Thanks @rudycelekli #3751）。

## 🤖 模型能力

- **新模型**：新增 `kimi-k3.1-pro`（Kimi 默认模型）、`MiniMax-M3.1-Flash`、`gpt-6.1-terra`（OpenAI 默认模型）、`claude-sonnet-5-5`、`claude-haiku-5-5`、`gemini-4-argon`（Gemini 默认模型）（Thanks @octo-patch #3791）。
- **小米 MiMo**：新增 `mimo-v2.5-asr` 语音识别；对话模型升级至 V2.6，旧模型 ID 自动映射（Thanks @592774447 #3788）。
- **模型显示名称**：自定义厂商的模型可设置显示名称，模型选择器中展示该名称，调用时仍使用原始模型 ID（Thanks @592774447 #3852）。
- **默认上下文**：Agent 默认上下文上限由 64K 提升至 200K Token，最大步数由 30 提升至 100，保留轮次由 20 提升至 30。
- **流式输出**：Claude 流式过程中的错误会如实返回，不再静默结束；兼容以断开连接作为结束标志的流式响应；各厂商流式连接在任意退出路径下均正确释放（Thanks @rudycelekli #3693, #3822、@a1094174619 #3847）。
- **OpenAI**：Responses 接口正确处理拒答内容、截断的工具参数与失败响应；图像接口重试时保留自定义地址（Thanks @rudycelekli #3691, #3692, #3702, #3706）。
- **追加消息**：智谱、通义千问、MiniMax 在工具结果之后保留运行中追加的消息；Gemini 非对象类型的工具结果正确封装（Thanks @rudycelekli #3825, #3826, #3827、@pei711 #3843）。
- **语音**：修复 MiniMax、Google、OpenAI 语音接口的连接释放、错误识别与地址拼接问题，相同文本重复合成时输出文件互不覆盖，手动朗读对应所点击的消息版本（Thanks @rudycelekli #3688, #3700, #3708, #3710, #3714, #3720, #3803）；识别结果异常时返回错误提示，各类回复路径下及时清理临时文件（Thanks @c020627 #3759, #3835, #3837、@rudycelekli #3815）。
- **其他**：Gemini 用量统计计入思考 Token，非流式响应同样返回准确的 Token 用量（Thanks @pcbeingused333 #3850, #3855）；ModelScope 流式响应兼容空 `choices` 数据块，模型能力列表互不干扰，识图失败时及时清理临时文件（Thanks @rudycelekli #3704, #3813, #3821）。

## 🛡 安全加固

- **定时任务权限**：定时执行的 Agent 任务沿用创建时所在会话的权限模式，只读会话中创建的任务无法执行写操作（Thanks @EddieMurphy89 #3833）。
- **访客请求防护**：代表访客发起的网络请求强制拦截本机与内网地址；访客页面密码不可与控制台密码相同。
- **控制台密码**：新设置的密码至少 6 位，输入时提示密码强度，已设置的密码不受影响。
- **资源限制**：模型返回文件的下载大小受限（Thanks @c020627 #3832）。
- **安全策略**：新增安全策略文档与私密漏洞报告渠道。

- **源码部署**：执行 `cow update` 一键升级，或在 Web 控制台侧边栏版本菜单中一键更新，也可手动拉取代码后重启。详见 [更新升级文档](https://docs.cowagent.ai/zh/guide/upgrade)。
