## 🌐 ゲストページ

Agent を独立したチャットページとして公開したり、チャットウィンドウとして Web サイトに埋め込んだりできます。訪問者はリンクを開くだけでログインなしで会話でき、製品に関する問い合わせ、ナレッジベース Q&A、カスタマーサポートなどに活用できます：

- **独立ページ**：ページごとに専用のリンクを発行し、訪問者の会話履歴を保持します。名前、アイコン、テーマカラー、ウェルカムメッセージ、おすすめの質問をカスタマイズできます。

</Frame>

- **ウィンドウ埋め込み**：コードを 1 つ貼り付けるだけで Web サイトに埋め込め、ページ右下にチャットボタンが表示されます。埋め込みを許可するサイトを制限でき、設定画面で埋め込み後の表示をそのままプレビューできます。

<Frame>
  <img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/guest-share-embed.png" alt="Web ページに埋め込む" width="800" />
</Frame>

- **データの分離**：訪問者に応答する Agent は、そのページに開放したツール、スキル、参考資料だけを使用でき、あなたのメモリ、会話、ワークスペースにはアクセスできません。コマンドは実行できず、ネットワークリクエストは公開アドレスに限られます。
- **参考資料**：ナレッジベースやそのカテゴリを読み取り専用の参考資料として直接選択でき、項目ごとに用途の説明を付けられます。
- **アクセス制御**：アクセスパスワード、1 人 1 日あたりの質問数、有効期限に対応します。訪問者ごとに会話記録を確認でき、リンクのリセット、ページの停止や削除もいつでも行えます。

## 🎨 カスタムテーマ

Web コンソールとデスクトップクライアントがテーマの切り替えに対応しました。両者は同じテーマフォルダを共有します：

- **テーマのインポート**：テーマの zip パッケージまたはフォルダをドラッグするだけでインポートでき、配色、背景壁紙、新規チャット画面のアイコンをカスタマイズできます。テーマは `~/cow/system/themes/` に保存されます。
- **Agent によるテーマ生成**：希望のスタイルを伝えるか参考画像を添付すると、Agent が配色、壁紙、アイコンを生成し、そのまま切り替えて使えます。
- **内蔵テーマ**：Meadow、Ocean、Clay、Sakura、Lavender の 5 つの配色テーマを用意しており、いずれもライトモードとダークモードの両方に対応しています。

## 🖼 メインモデルによる画像理解の改善

メインモデルがビジョンに対応している場合、画像をマルチモーダル入力として直接推論に渡し、1 回の呼び出しで理解から回答までを完結させます。画像理解ツールを介した間接的な説明による情報の欠落を防ぎ、UI の再現やグラフの分析などのタスクで精度が大きく向上します（Thanks @592774447 #3608）。

- **適用条件**：画像理解モデルを「自動」に設定するか、メインモデルと同じモデルにすると有効になり、追加の設定は不要です。
- **コンテキストの消費**：画像を送るのは現在のターンだけで、過去のターンには画像への参照のみを残すため、トークンが重複して計上されません。画像が原因でリクエストが拒否された場合は、テキストのみで自動的に再試行します。
- **プロバイダーへの対応**：Claude、Gemini、Qwen にはそれぞれのネイティブ形式で画像を渡します。
- **認識精度**：画像の圧縮上限を 3MB / 3072px に引き上げ、文字や細部をより多く保持します。

## 🔗 連携設定とアクセスアドレス

「設定」ページに「連携設定」を追加しました。Web コンソールとデスクトップクライアントの両方に対応し、ゲストページ、チャット API、アクセスアドレスをまとめて管理できます：

- **アクセスアドレス**：リスンする IP とポートをオンラインで変更でき、サービスは新しいアドレスで自動的に再起動します。新しいアドレスが使えない場合は元のアドレスに戻ります。このマシンのローカルネットワークアドレスが表示され、共有リンクと埋め込みコードに使う表示アドレスも設定できます。
- **HTTPS とドメイン**：証明書を設定すればコンソールから直接 HTTPS で配信できるようになり、nginx リバースプロキシでのデプロイ手順もドキュメントに追加しました（Thanks @anshlakhera048 #3774、@592774447 #3768）。
- **ログイン保護**：同じ接続元からパスワードを続けて間違えると一時的にロックされます。このマシンからのアクセスは別にカウントされるため、外部からパスワードを推測されても、このマシンからログインできなくなることはありません。
- **チャット API**：同じ会話への同時リクエストを順番に処理します（Thanks @rudycelekli #3751）。

## 🤖 モデル機能

- **新モデル**：`kimi-k3.1-pro`（Kimi のデフォルトモデル）、`MiniMax-M3.1-Flash`、`gpt-6.1-terra`（OpenAI のデフォルトモデル）、`claude-sonnet-5-5`、`claude-haiku-5-5` を追加しました（Thanks @octo-patch #3791）。
- **Xiaomi MiMo**：音声認識の `mimo-v2.5-asr` を追加しました。チャットモデルを V2.6 に更新し、旧モデル ID は自動的に対応付けられます（Thanks @592774447 #3788）。
- **モデルの表示名**：カスタムプロバイダーのモデルに表示名を設定でき、モデル選択画面にはその名前が表示されます。呼び出しには元のモデル ID が使われます（Thanks @592774447 #3852）。
- **デフォルトのコンテキスト**：Agent のデフォルトのコンテキスト上限を 64K から 200K トークンに、最大ステップ数を 30 から 100 に、保持するターン数を 20 から 30 に引き上げました。
- **ストリーミング出力**：Claude のストリーミング中に発生したエラーを、黙って終了せずにそのまま返すようにしました。接続の切断を終了の合図とするストリーミング応答に対応し、各プロバイダーのストリーミング接続はどの終了経路でも正しく解放されます（Thanks @rudycelekli #3693, #3822、@a1094174619 #3847）。
- **OpenAI**：Responses API で拒否応答、途中で切れたツール引数、失敗した応答を正しく処理します。画像 API の再試行時にもカスタムのアドレスを保持します（Thanks @rudycelekli #3691, #3692, #3702, #3706）。
- **実行中の追加メッセージ**：Zhipu GLM、Qwen、MiniMax で、実行中に追加されたメッセージをツール結果の後に保持します。Gemini ではオブジェクト以外のツール結果を正しくラップします（Thanks @rudycelekli #3825, #3826, #3827、@pei711 #3843）。
- **音声**：MiniMax、Google、OpenAI の音声 API で、接続の解放、エラーの判定、アドレスの組み立ての問題を修正しました。同じテキストを繰り返し合成しても出力ファイルが上書きされなくなり、手動の読み上げはクリックしたメッセージのバージョンを再生します（Thanks @rudycelekli #3688, #3700, #3708, #3710, #3714, #3720, #3803）。認識結果が異常な場合はエラーを返し、どの返信経路でも一時ファイルを速やかに削除します（Thanks @c020627 #3759, #3835, #3837、@rudycelekli #3815）。
- **その他**：Gemini の使用量に思考トークンを含めるようにしました（Thanks @pcbeingused333 #3850）。ModelScope のストリーミング応答で `choices` が空のチャンクに対応し、モデルの機能リストが互いに影響しなくなり、画像認識に失敗した場合も一時ファイルを速やかに削除します（Thanks @rudycelekli #3704, #3813, #3821）。

## 🧩 スキルとツール

- **Web 検索**：DeepSeek 公式の Search API と Fetch API に対応しました。DeepSeek の API キーを設定すると自動的に有効になり、デフォルトの検索プロバイダーとして使われます（Thanks @anshlakhera048 #3776、@592774447 #3775）。認証情報を残したまま特定の検索プロバイダーだけを無効にでき、キー不要の匿名検索は明示的に有効にする必要があります（Thanks @rudycelekli #3705）。
- **スキル**：デスクトップクライアントのスキルページにアイコンとバージョンを表示します。`skill_hub_url` でカスタムのスキルリポジトリを設定でき、名前でのインストールと検索に対応し、収録されていないスキルはデフォルトの Skill Hub から取得します。会話中のスキルコマンドは現在の Agent にのみ適用されます。
- **スキル管理**：置き換えのインストールに失敗した場合は元のスキルを保持し、有効化・無効化に失敗した場合は元の状態に戻します。BOM 付きのファイルやさまざまなメタデータ形式に対応し、1 つの設定項目が壊れていても他のスキルに影響しなくなりました（Thanks @rudycelekli #3685, #3690, #3695, #3696, #3698, #3711, #3753, #3754、@c020627 #3760）。
- **ターミナル**：Windows でコマンドの出力がない問題と、複数行の Python コマンドが途中で切れる問題を修正しました（Thanks @keeponlight #3795、@rudycelekli #3811、@Nolan527 #3793）。非常に長い行を切り詰めた後も完全な出力を保持します（Thanks @rudycelekli #3779）。
- **構文チェック**：書き込み前の構文チェックで、`tsconfig.json`、VS Code の設定、Helm テンプレートなど、コメントやテンプレート構文を含むファイルを扱えるようにしました。`package.json` などの厳密な JSON ファイルでは引き続きコメントをブロックし、修正方法を示します（Thanks @tanishqbaweja #3853）。
- **ファイルの読み書きと検索**：あいまい一致による編集で、置き換えた内容の前後に空行が増えなくなりました（Thanks @tanishqbaweja #3854）。非常に長い行をオフセット指定で読み取れるようになり、CR 改行とあいまい一致時のインデントを保持し、文字コードのフォールバックに失敗した場合は元のファイルを上書きしません。ディレクトリや特殊ファイルの読み書きを拒否し、ファイルの読み取り記録は現在の会話の範囲に限定されます。ripgrep がインストールされていない場合もディレクトリのフィルターが適用されます（Thanks @rudycelekli #3689, #3715, #3752, #3770, #3772, #3794, #3799, #3810）。
- **ドキュメントの解析**：Word のコンテンツコントロール、フィールドの結果、結合セルを完全に読み取り、Excel では宣言範囲外のセルも読み取ります（Thanks @ningyixi #3786, #3787、@rudycelekli #3773, #3777, #3798）。
- **ブラウザ**：スナップショットを特定の要素に限定でき、スクリーンショットは現在のプロジェクトに保存され、入力欄は明確なテキストが指定された場合にのみ入力します。ブラウザのプロファイルディレクトリを厳密に照合し、似たパスを使用中と誤判定しなくなりました。Windows でのプロセス検出にタイムアウトを設けました（Thanks @rudycelekli #3724, #3725, #3727, #3802、@c020627 #3769）。
- **画像理解**：圧縮した画像で元の表示の向きを保持し、モデルが空の結果を返した場合は次のプロバイダーを試します（Thanks @rudycelekli #3712, #3726, #3806）。
- **MCP とスケジュールタスク**：MCP の接続失敗をツール呼び出しの失敗として返し、壊れた認可記録は無視します。スケジュールタスクの実行結果を個々の実行に正確に対応付け、実行中に変更したスケジュールが上書きされなくなり、拒否された操作は失敗として返します。旧形式のリマインダーの移行もより確実になりました（Thanks @rudycelekli #3713, #3745, #3781, #3782, #3807, #3808）。

## 🤝 マルチ Agent 協調

- **サブ Agent**：詳細な調査など必要な場合にのみ委任し、タイムアウトが近づくと処理をまとめて、それまでに得た結果を返します。ローカルでの委任は設定したタイムアウトに従い、引数の誤りやテンプレートディレクトリを読み取れない場合も中断しなくなりました（Thanks @rudycelekli #3783、@c020627 #3761）。
- **チーム協調**：@メンションの直後に句読点が続く場合も正しく認識します（Thanks @c020627 #3738）。
- **コンテキスト**：ループ検出のヒントはモデルが参照した後に削除され、コンテキストに残らなくなりました（Thanks @NotZhu #3851）。コンテキストをクリアした後の新しいメッセージを正しく保持し、チャネルでの会話の実行ステップの履歴への書き込みが一時的に失敗した場合は自動で再試行するため、ツールの記録が失われなくなりました（Thanks @rudycelekli #3734, #3804）。

## 📡 チャネル機能

- **WeChat**：QR コードでのログインがより安定し、期限切れの QR コードは自動で更新されます。オプションで `weixin_proxy` プロキシを設定できます（Thanks @c020627 #3838）。送信するファイルは元のファイル名と種類を保持します（Thanks @6vision #3817）。メディアのダウンロードに失敗した場合に接続が解放されない問題を修正しました（Thanks @rudycelekli #3750）。
- **Feishu**：リッチテキストメッセージでファイルと多言語の本文を解析できるようになりました。
- **ファイル送信**：Feishu、DingTalk、WeCom Bot、WeChat カスタマーサービスでファイルを送信する際に元のファイル名を保持します。
- **DingTalk**：グループチャットのファイルを送信者ごとに区別し、メディアの一時ファイルを速やかに削除します（Thanks @rudycelekli #3762、@c020627 #3828）。
- **WeCom / WeChat 公式アカウント**：WeCom で保存した画像は元の表示の向きを保持します（Thanks @c020627 #3845）。公式アカウントでチャットのプレフィックスを設定していない場合も、フォロー時のウェルカムメッセージが正しく送信されます（Thanks @rudycelekli #3707）。
- **Telegram / Discord / Slack**：リモート URL のファイルを送信できるようになりました。グループチャットでのボットへの @メンションはユーザー名を完全一致で判定し、サイズの大きすぎる添付ファイルはダウンロード前にブロックし、ワークスペースのシステム通知には返信しなくなりました（Thanks @rudycelekli #3716, #3764, #3765, #3818, #3819, #3820）。
- **プラグイン**：グループ管理者を ID で厳密に照合します（Thanks @rudycelekli #3763）。

## 🛡 セキュリティ強化

- **スケジュールタスクの権限**：スケジュール実行される Agent タスクは、作成時のセッションの権限モードを引き継ぎます。読み取り専用のセッションで作成したタスクは書き込み操作を実行できません（Thanks @EddieMurphy89 #3833）。
- **ゲストのリクエスト保護**：訪問者に代わって行うネットワークリクエストでは、ローカルおよび社内ネットワークのアドレスを常にブロックします。ゲストページのパスワードはコンソールのパスワードと同じものを使えません。
- **リソースの制限**：モデルが返すファイルのダウンロードサイズを制限しました（Thanks @c020627 #3832）。
- **セキュリティポリシー**：セキュリティポリシーのドキュメントと、脆弱性を非公開で報告する窓口を追加しました。

## 🛠 使い勝手の改善と修正

- **会話操作**：返信の生成中も自由に上へスクロールして確認でき、最下部へ戻るボタンが入力欄と揃って表示されます。最上部までスクロールすると以前のメッセージを自動で読み込みます（Thanks @LYLMagui #3785）。入力エリアの空白部分をクリックすると入力欄にフォーカスします（Thanks @Rofds #3830）。
- **動作の滑らかさ**：返信がまとめて届いたときに画面が固まる問題を修正しました。長いセッションでは画面外のメッセージを描画しないため、入力とスクロールがより滑らかになりました（Thanks @zkjqd #3792）。
- **ワイド画面への対応**：デスクトップクライアントのチャットエリアがウィンドウの幅に合わせて広がります（Thanks @zkjqd #3844、@592774447 #3839）。
- **セッション**：再起動後もコンテキスト使用量のグラフを保持します（Thanks @xiao115255 #3767、@jiangch1128 #3619）。メインモデルの呼び出しに失敗した場合はフォールバックモデルでタイトルを生成し、メッセージの送信に失敗した場合は具体的な理由を表示し、削除に失敗した場合は元の会話記録を保持します（Thanks @rudycelekli #3809）。
- **ファイルの表示**：ワークスペース外のファイルを送信すると自動でワークスペースにコピーされ、コンソールで正しく表示されます。読み込めない画像にはファイル名を表示します。デスクトップクライアントのファイルプレビューから、ファイルをフォルダ内で表示できます。
- **ナレッジグラフ**：相互参照を解決できず、ノードのタイトルがなくなり接続線がすべて失われる問題を修正しました。ナレッジベースのルートからの相対パス、ファイル名のみ、山括弧などの書き方や、ナレッジベースのディレクトリがシンボリックリンク配下にある場合にも対応します。
- **コンソール**：設定の保存に失敗した場合は実行中の設定を保持し、ワークスペースのファイルを同時に保存すると競合を通知します。ワークスペースのファイルの更新、エディタの内容の検証、個人設定の保存、リクエストのキャンセル範囲などの問題を修正しました。登録済みの Agent ワークスペース内の成果物に正しくアクセスでき、ナレッジベースのドキュメントの置き換えもより確実になりました（Thanks @rudycelekli #3733, #3746, #3747, #3748, #3749, #3755, #3784, #3801, #3805）。
- **Agent の初期化**：ID ファイルが空でも初回のガイドがスキップされなくなり、同時に初期化しても既存の設定が上書きされなくなりました（Thanks @rudycelekli #3722, #3730）。軌跡の評価で、期待するツールと実行状態を正しく検証します（Thanks @xiong-wei1 #3849, #3848）。
- **ログと CLI**：ログファイルが切り詰められた後もリアルタイムログの出力を続け、データディレクトリに書き込めない場合もコンソールへの出力を保持します。バックグラウンドで起動したサービスは標準入力から切り離され、権限不足でプロセス ID が失われる問題や、更新状態ファイルが壊れる問題を修正しました（Thanks @rudycelekli #3686, #3687, #3709, #3717, #3719, #3780, #3800, #3812, #3814）。
- **設定とバックアップ**：データディレクトリを同時に作成してもエラーにならなくなり、リモートから送られた設定は実際に読み込まれるデータディレクトリに書き込まれ、バックアップの復元後もスキルのスクリプトの実行権限を保持します（Thanks @rudycelekli #3723, #3778、@c020627 #3823）。
- **デスクトップクライアント**：内蔵バックエンドのバージョンがクライアントと一致するようになりました（Thanks @592774447 #3839）。Windows でのインストール時にファイルのコピーに失敗した場合は、自動的に再展開します。

## 📦 アップグレード方法

- **ソースデプロイ**：`cow update` でワンクリック更新するか、Web コンソールのサイドバーのバージョンメニューから更新するか、最新コードを取得して再起動します。詳しくは[アップグレードガイド](https://docs.cowagent.ai/ja/guide/upgrade)を参照してください。
- **デスクトップクライアント**：クライアント内で更新を確認してワンクリックで更新するか、[ダウンロードページ](https://cowagent.ai/download/)から最新版を入手できます。
